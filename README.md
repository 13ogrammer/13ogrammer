### Hi, I'm Prabs 👋

Full Stack Engineer (10+ years) — Ruby on Rails, React, AWS — currently at **Sesimi** (formerly My Adbox), Melbourne. I own ambiguous, cross-team technical problems end-to-end: rearchitected a critical data pipeline from 1–2 days down to under an hour, built a custom Rack-level defence layer that stopped malicious traffic before it hit the database, and grew automated test coverage from ~35% to 80–90% by building a testing culture across three engineering teams.

**Right now, outside the day job**, I'm self-directed studying generative AI systems — RAG pipelines, agent evaluation, and guardrail design. These repos are that study, built as working code rather than tutorials followed:

- 🏗️ [**ai-engineering-platform**](https://github.com/13ogrammer/ai-engineering-platform) — reusable infrastructure for AI apps: context engineering, retrieval, evaluation, tool integration, agent orchestration, and observability.
- 🧪 [**agent-evals**](https://github.com/13ogrammer/agent-evals) — evaluating whether agents use tools correctly and stay grounded in real data, not just whether the output "sounds right."
- 🔍 [**progressive-rag-development**](https://github.com/13ogrammer/progressive-rag-development) — RAG built stage by stage (naive → hybrid search + rerank → query intelligence), each stage fixing a specific failure mode of the last.
- ☁️ [**s3-backup**](https://github.com/13ogrammer/s3-backup) — cross-platform mobile backup app where credentials and data never touch a third-party backend.
